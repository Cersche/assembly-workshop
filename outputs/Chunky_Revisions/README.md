# Chunky Revisions

Brackets that hang on the rack posts with **post rails** (Brian, 2026-10-30): rails bolt to the posts' middle front holes, the tray slides in on runners, and the tray is also screwed to the faceplate with the hidden M6 joint. New brackets and revisions of existing ones that use this pattern go here, one folder each.

Brian's rack uses the creator's **4U posts**: away from the post ends the side wall is solid (14 mm, inner face X ±127.12) with no holes, so rails use the middle front holes only. Check every design against the 4U post mesh (object_190 in `work/rack-geometry-recovery/sources/Lab+Rax+1-5U+Posts+&+Panels.3mf`; licensed, local only).
