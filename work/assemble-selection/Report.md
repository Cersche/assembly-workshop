# Assemble viewer selection — 2026-10-18

Added the same cyan selection rim/subtle tint to the existing Assemble inspection viewer. Faceplate, tray and visible reference parts can be selected by clicking. The status identifies the selected part. Repeated reference hardware of the same kind is grouped. Click empty canvas or press Escape to clear. Dragging or arrow-key orbit preserves selection; a click no longer exits faceplate-front mode. Hiding a selected part or changing assembly meshes clears selection.

The existing software depth rasterizer now optionally writes a per-pixel part-ID buffer alongside its nearest-surface result. Picking reads the displayed pixel's owner at the correct display/device scale. Tint/rim shade only pixels owned by the selected part, including hole boundaries, without painting over foreground parts or background. Texture/color/model inputs remain unmodified. This change adds selection to the existing inspection renderer; it does not replace its orthographic rendering engine or change manufacturing meshes.
