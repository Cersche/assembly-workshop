# CM1000 bracket reference (local only)

`CM1000_1U_10in_bracket_body.stl` is the main body (object 3) extracted unchanged from
`Y:\CM1000_1U_10in.3mf`. That file is a community 10-inch 1U remix of @Jsmaz3's 19-inch
CM1000 ear from Printables. Brian reports it fits the modem very well.

Brian's direction (2026-10-19): this is a remix for personal use. Copy the geometry if it
improves accuracy, and **do not redistribute it**. The original license is UNKNOWN. Keep this
file out of release packages, uploads and commits.

Coordinates are the 3MF's, in mm. X runs across the bracket (254 mm wide), Y is height
(±22.225 = 1U), and Z is depth (front faceplate at +68.81).
