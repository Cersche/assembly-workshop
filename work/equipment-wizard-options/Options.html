Adding equipment and placing it on a tray — 3 options

Static mockups for Brian to compare. Nothing here is built. Fit, retention and strength of every mounting method stay UNKNOWN; drafts still only save on Save. Device shown is a generic box, not a Pi.

What the current code does (why the options look like this)

  • The wizard (equipment-wizard.js) is one 5-step dialog: Device → Mounting → Ports → Faceplate → Generate. It mixes facts about the equipment (size, holes, ports) with choices about the tray (mounting method, standoff, keystones, rear support).
  • Placing on a tray today is "select an empty slot, click a library card". There is no move step: equipment_tray.scad always centres the device left-right and puts it a fixed 12 mm (front_gap) behind the faceplate.
  • So any placement window needs three new tray settings: left/right offset, front/back offset, and rotation (0/90/180/270). Screw positions already follow from the device's hole list, so showing them is a preview of existing data.
  • Suggested split for all options: library entry = facts about the equipment (name, size, model file, holes, ports). Tray placement = choices (position, rotation, mounting method, standoff, faceplate/keystones). One library item can then go on many trays different ways.
