Blank faceplates — options

A plate in a slot with nothing behind it. 44.4 mm per U, 252 wide, 4 thick, 2.5 mm corners, four-corner slots. Fit and strength stay UNKNOWN.

1U blank with four keystones (sketch, not to scale).

A. "Blank plate" slot choice (recommended)

When you pick a slot you get a new choice next to "Create assembly": Blank plate. You set height (1U, 2U, 3U…), then go straight to the same Setup / Hardware / Appearance tabs. No device, no tray, no wizard steps. Keystones use the new keystone picker on the plate face.

Behind the scenes it reuses the wizard's faceplate-only part (equipment_tray.scad already has part="faceplate"), so the plate is the same proven shape as every other faceplate. Smallest change, fastest to use.

B. "Blank plate" library item

A saved item in the Equipment library ("Blank 1U", "Blank 2U", "Patch 1U · 6 keystones"). You drop it in a slot like any equipment, and can save your own patch-panel layouts to reuse.

Good if you'll repeat the same patch panel in many racks. Needs a "no device" kind of library item, a bit more work.

C. Both

A's quick slot choice, plus "Save to library" to reuse a layout later. Build A first, add the library part when you want it.

Same for every option

  • Height: 1U and up, holes on every U like now.
  • Rear support: none needed — nothing hangs off it. Keystone jacks + cables are light; the plate is held by its four corners per U. (Strength still UNKNOWN.)
  • Keystones: same keystone picker the keystone-picker session is building, same golden keystone. Labels too, once keystone-labels lands.
  • Paint and images: color presets / custom color / image fit work in the preview like other faceplates.
  • Export: one STL — the plate.
